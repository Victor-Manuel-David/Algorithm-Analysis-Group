Análisis de Algoritmos · Examen 3 · Programación Dinámica

¿Qué charlas programar en un auditorio para tener la mayor asistencia?

Un congreso tiene un solo auditorio y muchas charlas propuestas. Cada una tiene hora de inicio, hora de fin y asistentes esperados. Las que se cruzan no pueden darse juntas. Probar todas las combinaciones cuesta O(2ⁿ); con Programación Dinámica (Weighted Interval Scheduling) se resuelve en O(n log n).

El voraz por hora de fin elige A + B = 20. El óptimo es Grande = 100. La DP compara tomar vs. no tomar en cada paso, reutilizando subproblemas.

1

Modelo de Programación Dinámica

Primero se ordenan las charlas por hora de fin y se numeran 1..n.

Estado / subproblema

dp[i]

Máximo de asistentes usando solo las primeras i charlas.

Caso base

dp[0] = 0

Sin charlas no hay asistentes. Es el punto de partida de la tabla.

Relación de recurrencia

dp[i] = max( dp[i−1] , wi + dp[p(i)] )

No tomar la charla i (queda lo mejor de las anteriores) o tomarla (sus asistentes + lo mejor compatible). p(i) = cuántas charlas terminan antes de que empiece la i (búsqueda binaria).

Respuesta

dp[n]

Las charlas elegidas se reconstruyen recorriendo la tabla de n hacia atrás.

Complejidad

O(n log n)

Ordenar + calcular p(i); llenar la tabla es O(n). Espacio O(n).

¿Cuánto trabajo ahorra la DP?

La recursión sin memoria vuelve a resolver los mismos dp[j] muchas veces (subproblemas solapados). Guardándolos, cada uno se calcula una sola vez. Escala logarítmica.

5

Implementación

Núcleo de js/dp.js (bottom-up). También se incluye la versión top-down con memoización.

// Ordenar por hora de fin y calcular p(i) con búsqueda binaria — O(n log n)
const ordenadas = ordenarPorFin(actividades);
const p = calcularP(ordenadas);

const dp = new Array(n + 1).fill(0);   // dp[0] = 0  → caso base
for (let i = 1; i <= n; i++) {
  const sinTomar = dp[i - 1];                       // no tomar la charla i
  const tomando  = ordenadas[i - 1].peso + dp[p[i]];  // tomarla
  dp[i] = Math.max(sinTomar, tomando);                // recurrencia
}

// Reconstrucción: de n hacia atrás
let i = n;
while (i > 0) {
  if (ordenadas[i - 1].peso + dp[p[i]] > dp[i - 1]) { seleccionadas.push(ordenadas[i - 1]); i = p[i]; }
  else i -= 1;
}
return dp[n];
